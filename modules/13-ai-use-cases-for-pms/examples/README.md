# Module 13 — Examples

Scripts and templates supporting the use-case scoring, ROI estimation, and
business-case sections of the module README. No API key or special setup
required — these are plain Python (standard library only) and Markdown.

## Contents

| File | Demonstrates |
|---|---|
| [`01_use_case_scoring.py`](01_use_case_scoring.py) | Impact/Feasibility/Risk scoring and tiering (README Section 3) over a sample backlog |
| [`02_roi_estimator.py`](02_roi_estimator.py) | Monthly savings and payback-period estimate from cost/volume assumptions (README Section 4) |
| [`templates/one_pager_template.md`](templates/one_pager_template.md) | Fill-in-the-blanks business-case template (README Section 4) |

Run either script directly:

```bash
python 01_use_case_scoring.py
python 02_roi_estimator.py
```
